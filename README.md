# claroverde.nl

Broncode van de website van Claro Verde: één pagina in het Nederlands (`index.html`) en één in het Engels (`en/index.html`). Handgeschreven HTML en CSS, zonder bouwstap, zonder cookies en zonder externe verzoeken.
